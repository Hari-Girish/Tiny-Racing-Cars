This is our project folder for our Tiny Racing Cars (Drag Race Victory Detector and Tracker) Computer Vision Project.

The goal of this project is to process a sequence of images depicting a drag race between two toy cars in order to determine a winner between them. Additionally, we aimed to track both cars throughout the race in order to deterine their paths traveled and current speed/distance.
We consider two race scenarios in our project. First, a speed race where two cars are racing to reach a finish line first. Second, a distance race in which the two cars are trying to travel the furthest before the end of the race.


The final image sequences used in our processing and tracking can be found in the SpeedRace folder and the DistanceRaceNew folder.

The DistanceRace3 folder contains the original distance race images that were ultimately not used due to a lack of clean results. This folder, as well as the original file used to experiment with processing it, patel_distance_race3.py, have still been included for reference.
